# Ограничения прототипа

- Ссылки шапки, подвала и «Открыть модель» открываются в новой вкладке на исходном сайте; форма обратного звонка ничего не отправляет.
- Корзина («В корзину» → счётчик в шапке → выезжающая корзина) работает; оформление заказа скрыто, а `serve.py` блокирует `submit.php`/`hit.php`, чтобы из прототипа не ушёл реальный заказ.
- Наличие у основной модели показывается всегда: у моделей без цветов берётся `available` из каталога («В наличии» / «Нет в наличии»).
- Сравнение: основная модель не дублируется, в чипах альтернатив нет цены, вывод «Почему основная модель выше» разбит на заголовок и описание.
- Строка «ориентир для базовой комплектации» и 3 аргумента «Почему подходит» скрыты.

- Локальный сервер слушает только `127.0.0.1`, служебные скрытые файлы не выдаются.
