# Промо Smart Calculator для README

Запись настоящего прототипа в headless Chromium (Playwright) и монтаж зацикленного WebP — по тем же правилам, что промо Agent Pulse: фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20, без курсора, клики показаны кольцами, плавная камера, последний кадр совпадает с первым.

Результат: `docs/assets/smart-calculator-demo.webp`, 1600 × 1030, 31 с, 30 к/с, сжатие с потерями (качество 75), ≈16 МБ. Запись идёт с шагом 60 к/с; при `--fps 60` файл ≈28 МБ.

## Как воспроизвести

Временные файлы и окружение — вне репозитория.

```sh
python3 -m venv /tmp/sc-promo-env
/tmp/sc-promo-env/bin/pip install playwright pillow numpy imageio-ffmpeg
/tmp/sc-promo-env/bin/python -m playwright install chromium
/tmp/sc-promo-env/bin/python scripts/promo/promo.py /tmp/sc-promo
cp /tmp/sc-promo/smart-calculator-demo.webp docs/assets/
```

Скрипт сам поднимает `serve.py`. Фото и ответы API исходного сайта скачиваются один раз в `ПАПКА/cache.pickle`; если сайт ответил ошибкой, запуск останавливается — просто повторить. Запись — около 8 минут.

Ключи: `--only-record`, `--only-compose` (монтаж из готовых кадров), `--keys-only` (только контрольные PNG в `ПАПКА/keys/` с шагом 0,5 с), `--fps`, `--quality` (сжатие WebP). `PROMO_LIMIT=7` записывает только первые 7 секунд — для отладки сценария.

## Как устроено

- **Виртуальное время.** Часы Playwright двигают таймеры и `requestAnimationFrame`, а CSS-анимации и переходы ставятся на паузу и перематываются на то же время. Каждый кадр 60 к/с снимается без пропусков, сколько бы ни шёл скриншот.
- **Только калькулятор.** Шапка и подвал сайта скрыты; корзина и оформление в сценарии не участвуют.
- **Клики** — настоящие клики мыши по центрам измеренных элементов; кольцо рисуется в той же точке. Ползунки ведутся теми же событиями `input`/`change`, что браузер шлёт при перетаскивании; кольцо идёт за бегунком.
- **Найдено при записи.** Центр слова соседней среды на баннере перекрыт фото техники (`img.tlsc-territory__machine`), клик туда не переключает среду. Скрипт кликает в видимую часть слова.
- **Петля.** В конце сценарий возвращает параметры к исходным, камера — к общему плану; скрипт сверяет первый и последний кадр (`Стык петли: RMS …`).

## Сценарий

Стиль «Экстремальный» → сезон «Зима» (смена модели) → бюджет до 4 млн → «Мощность: Максимум» → вкладки «Сравнение» с выбором альтернативы, «Профиль», «Почему подходит» → «Как мы пришли к этому выбору» и выбор финалиста → баннер среды, переход к «Горам» → возврат параметров к исходным.
